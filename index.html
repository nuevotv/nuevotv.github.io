NuevoTV

Envoie une playlist, tes clés API ou un fichier de sauvegarde vers une TV, où qu'elle soit. Le code s'affiche sur la TV dans Réglages → Ajouter de n'importe où.

Tout est chiffré sur ton téléphone avec le code de la TV avant d'être envoyé : le relais (ntfy.sh) ne voit jamais tes identifiants. La TV le reçoit dans les secondes qui suivent si NuevoTV est ouverte, sinon au prochain démarrage (dans les 12 heures).
